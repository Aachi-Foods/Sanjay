# BnR Event Planners — Website

South India's premier event planning studio, across every faith and
celebration — Hindu, Muslim, Sikh, Christian, and interfaith weddings,
receptions, and corporate events.

This branch is a standalone copy of the site: the Next.js app lives in
[`bells-n-rings-multipage-site/`](./bells-n-rings-multipage-site), with its
own [README](./bells-n-rings-multipage-site/README.md) for local setup and
[CONTENT.md](./bells-n-rings-multipage-site/CONTENT.md) for the checklist of
placeholder content to replace before launch.

Pushes to this branch build and deploy automatically to GitHub Pages via
`.github/workflows/nextjs.yml`.
